# 🎮 Tic-Tac-Go Game

A simple, interactive, and fun Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**. Two players can play against each other on a 3×3 grid, take turns, and compete to win the game.

## ✨ Features

* 🎯 Two-player gameplay (X and O)
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔄 New Game functionality
* 🎮 Reset Game functionality
* 🎨 Clean and user-friendly interface
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** — Structure of the game
* **CSS3** — Styling and layout
* **JavaScript** — Game logic and interactivity

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/mayanktiwari5588/Tic-Tac-Go-Game.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Start playing and enjoy the game!

## 🎯 How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three marks in a row, column, or diagonal wins.
4. If all cells are filled and nobody wins, the game ends in a draw.
5. Click the New Game or Reset button to play again, if available.
